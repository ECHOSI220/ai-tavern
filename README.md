# 幻境酒馆 AI Tavern

Windows 与 Android 版 AI 角色扮演、聊天与跑团应用。

## 下载

[查看最新版本与安装包](https://github.com/ECHOSI220/ai-tavern/releases/latest)

- [Windows x64 ZIP](https://github.com/ECHOSI220/ai-tavern/releases/download/v1.0.36/ai-tavern-v1.0.36-web-links-windows-x64.zip)：完整解压后运行 `ai_tavern.exe`，保留同目录 DLL 和 data 文件夹。
- [Android arm64 APK](https://github.com/ECHOSI220/ai-tavern/releases/download/v1.0.36/ai-tavern-v1.0.36-web-links-arm64.apk)：适用于 64 位安卓手机，下载后安装。

更新前建议备份重要本地存档。安装包校验值见对应版本发布说明。

## 网页社区
